# Student Management System (SQL Project)

## Overview

The Student Management System is a database mini project developed using MySQL. It stores and manages student, course, and enrollment information using SQL tables and relationships. This project demonstrates basic DBMS concepts such as primary keys, foreign keys, joins, grouping, and data manipulation queries.

## Features

* Create a Student Management database.
* Store student details in a structured table.
* Store course information.
* Manage student enrollments and marks.
* Use primary key and foreign key relationships.
* Perform CRUD operations using SQL.
* Execute JOIN, GROUP BY, ORDER BY, UPDATE, and DELETE queries.

## Database Tables

### Students

Stores student information such as:

* Student ID
* Name
* Gender
* Department
* Year
* Email
* Phone Number

### Courses

Stores course details such as:

* Course ID
* Course Name
* Faculty Name
* Credits

### Enrollments

Stores enrollment details including:

* Enrollment ID
* Student ID
* Course ID
* Marks
* Grade
